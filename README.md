# 麒麟步迹

三星手表高德地图导航工具。

## 功能

- 支持步行、骑行导航，显示转向箭头、距离、路名和局部路线。
- 显示剩余里程、预计用时、当前时间及八方向朝向。
- 支持息屏导航显示、常亮和省电模式，转弯时震动提醒。
- 手机粘贴高德路线链接或手动设置起终点，一键发送到手表。
- 手机负责 GPS 定位、路线规划、偏航重算和实时导航；手表只显示指引与震动提醒。
- 手机、手表界面和导航通知均可结束导航；断连超时自动停止。
- 手机查看、导出导航调试记录。

## 使用

1. 在手机高德规划路线，分享并复制链接。
2. 打开手机端麒麟步迹，粘贴链接，点击“开始手机导航并打开手表”；首次使用在手机同意隐私说明并授予精确定位权限。
3. 在手表确认接收导航；导航界面底部直接点击“结束导航”，或从手机、两端通知结束。长按屏幕仍可切换显示模式。
4. 结束会停止手机 GPS/导航引擎，以及手表同步服务、震动、方向传感器和常亮。手表默认省电显示。

测试设备：**三星 Galaxy S25+、Galaxy Watch 6 Classic**。

**当前手表应用只能通过 ADB 安装。** 安装后日常使用无需 ADB，手机需联网并随身携带，手机与手表需保持配对通信；手表无需独立联网算路。

**从 0.4 升级请同时更新手机与手表到 0.5。** 通信协议已升级，旧版手表不会接收新版本路线。高德 Key 现在仅配置在手机 APK；详细职责与超时规则见[导航架构](docs/navigation.md)。上方截图保留为 0.4 界面示例。

## 申请 Key

1. 登录[高德开放平台控制台](https://console.amap.com/dev/key/app)。
2. 进入“我的应用”，选择应用，点击“添加 KEY”；没有应用则先创建。
3. 选择 **Android 平台**，按页面要求填写信息并提交。
4. 将申请到的 Key 填入本地配置文件，再构建安装。具体见[配置与安装](docs/install.md)。

请使用自己的 Key，不要公开上传 Key 或含私人 Key 的安装包。
