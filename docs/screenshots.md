## 复现

1. 使用空 Key，运行 `./gradlew.bat -Pshowcase :phone:assembleDebug :watch:assembleDebug`。
2. 在三星 Galaxy S25+ / Galaxy Watch 6 Classic 安装各自 APK。展示包名独立于导航应用，不读取其私有数据。
3. 手机打开应用，点击“加载上海测试路线（不定位）”；手表打开展示应用即进入导航界面预览。
4. 分别通过 `adb -s <设备标识> exec-out screencap -p` 将原始 PNG 字节保存到 `docs/images/phone-main.png`、`docs/images/watch-navigation.png`。Windows 上推荐使用 Python `subprocess.check_output` 写入字节，避免 PowerShell 文本重定向破坏图片。

展示构建隐藏手机系统状态栏，以免通知图标进入截图。截图不经过生成式修改，使用实际应用渲染界面；不包含 Key、设备序列号、真实位置、私人路线或调试日志。
